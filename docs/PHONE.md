# Phone channel — "Tom" calls Grandpa

Grandpa doesn't need an app: he gets a real phone call from **Tom** (the ElevenLabs agent) over a Twilio number.
Tom remembers previous conversations (memory injected as dynamic variables) and the call transcript flows back into
the same pipeline as web sessions (summary → open threads → people → tree matches → family book).

```
[Call Grandpa] ──POST /api/phone/call──► ElevenLabs /v1/convai/twilio/outbound-call ──► Twilio ──► 📱 rings
                                          (dynamic_variables = memory + session_id)
Grandpa calls the number ──► ElevenLabs ──POST /api/phone/init──► memory as dynamic_variables
Call ends ──► ElevenLabs ──POST /api/phone/post-call (HMAC signed)──► turns stored ──► finalizeSession()
UI polls GET /api/phone/status?sessionId=… every 3 s → "Call finished — memories saved"
```

## 1. Twilio (≈5 min)
1. Sign up at <https://www.twilio.com/try-twilio> (trial is fine, ~$15 credit).
2. Console → **Phone Numbers → Buy a number** → pick a number with **Voice** capability (a US number is fine and free on trial).
3. **Trial accounts can only call verified numbers**: Console → **Phone Numbers → Verified Caller IDs → Add a new Caller ID**
   → enter the presenter's own phone (E.164, e.g. `+420777123456`) and confirm the SMS/voice code.
   Also enable calls to that country: Console → **Voice → Settings → Geo permissions** → tick *Czech Republic*.
4. Copy **Account SID** and **Auth Token** from the console home page.

> Trial calls start with a short Twilio message ("You have a trial account…, press any key") — press a key and Tom starts talking.
> Upgrade the account (add $20) to remove it before the demo if possible.

## 2. Env vars (`.env.local` and Vercel)
```
ELEVENLABS_API_KEY=…            # already set
ELEVENLABS_AGENT_ID=…           # already set (scripts/create-agent.ts)
TWILIO_ACCOUNT_SID=AC…
TWILIO_AUTH_TOKEN=…
TWILIO_PHONE_NUMBER=+1…         # the Twilio number
GRANDPA_PHONE_NUMBER=+420…      # who "Call Grandpa" rings (the verified phone)
PUBLIC_BASE_URL=https://<your-deployment-or-tunnel>
# printed by the setup script:
ELEVENLABS_PHONE_NUMBER_ID=…
ELEVENLABS_POST_CALL_WEBHOOK_ID=…
ELEVENLABS_WEBHOOK_SECRET=…     # post-call HMAC secret; when set, signatures are verified strictly.
                                # Unset → accepted unsigned (production logs a warning). Set it ASAP.
ELEVENLABS_INIT_SECRET=…        # generated by the script if missing; sent by ElevenLabs as x-heirloom-secret to /api/phone/init
```

## 3. Run the setup script
```
npx tsx --env-file=.env.local --env-file=.env.production.local scripts/setup-phone.ts
```
It (1) imports the Twilio number into ElevenLabs if `ELEVENLABS_PHONE_NUMBER_ID` is unset, (2) assigns agent Tom to it,
(3) creates an HMAC post-call webhook → `PUBLIC_BASE_URL/api/phone/post-call` and prints its secret,
(4) sets the agent's conversation-initiation webhook → `PUBLIC_BASE_URL/api/phone/init` (with header `x-heirloom-secret`)
and enables it; post-call events = `transcript` + `call_initiation_failure`.
Copy the printed values into `.env.local` **and Vercel**, then redeploy.
Changing `PUBLIC_BASE_URL` later? Re-run with `--new-webhook`.

If a step fails, it prints the manual dashboard steps:
- ElevenLabs → Agents → **Settings** → *Post-call webhook* → create (HMAC) with URL `…/api/phone/post-call`, events *Transcript* + *Call initiation failure*.
- Same page → *Conversation initiation client data webhook* → `…/api/phone/init`, header `x-heirloom-secret: $ELEVENLABS_INIT_SECRET`.
- Agent Tom → **Security** → enable *Fetch conversation initiation data for inbound Twilio calls*.

## 5. Test
- Status: `curl $PUBLIC_BASE_URL/api/phone/status` → all booleans, `canCall: true`.
- Call: `curl -X POST $PUBLIC_BASE_URL/api/phone/call -H 'content-type: application/json' -d '{}'`
  → `{ sessionId, conversationId }`, phone rings. Always dials `GRANDPA_PHONE_NUMBER` (body `to` is ignored).
- After hanging up (≈10–30 s): `curl "$PUBLIC_BASE_URL/api/phone/status?sessionId=s3"` → `transcriptArrived: true`, then `finalized: true`.
- UI: drop `<CallButton />` (`components/phone/CallButton.tsx`) on any page, e.g. `/talk` or `/demo`.

## Notes / gotchas
- The agent's `first_message` is `{{first_message}}`, so the opener comes from memory. Extra dynamic variable `session_id`
  links the call to our session; the post-call handler also matches by `conversation_id`.
- The init webhook fires only for INBOUND calls: it always creates a new session and stores `conversation_id` on it.
  Outbound calls get their session + conversation id from `/api/phone/call`.
- Busy / no answer → `call_initiation_failure` webhook marks the session `failed`; the button shows "Grandpa didn't pick up".
  The button stops polling after 10 minutes.
- Post-call payloads that match no session create one only for phone calls (`metadata.phone_call` or `session_id` dynamic var);
  web `/talk` conversations are ignored (they already store their turns).
- Post-call handler dedupes by transcript index, so ElevenLabs retries are safe; finalize runs in `after()` (skipped if the session is already finalizing/done).
- If the transcript never arrives (webhook misconfigured), the session stays `live`; the web talk flow is unaffected.
